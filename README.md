# Свадебное интерактивное приглашение · Муродбек & Баргида 💍

> **Дата торжества:** 11 Октября 2026 года, 15:00  
> **Место проведения:** Ресторан «Grand Palace», ул. Счастливая, д. 7

Электронное интерактивное свадебное приглашение в виде премиальной цифровой открытки. Создано по принципу **Mobile-First** (адаптировано для идеального отображения на 90%+ мобильных устройств: iPhone, Samsung, Xiaomi и др.), без использования внешних растровых фотографий — вся графика выполнена на чистом векторном SVG и аппаратном Canvas.

---

## ✨ Особенности и функции

* ✉️ **Интерактивный 3D-конверт с сургучной печатью**:
  При входе гостя встречает роскошный фактурный конверт цвета слоновой кости с тиснением и мерцающей сургучной печатью с монограммой «М & Б». При тапе печать с приятным звуком раскрывается, клапан распахивается в 3D, происходит салют из лепестков роз и конфетти, и приглашение выплывает на экран.
* 🌸 **Цветущие лепестки от касания (Tap-to-Bloom)**:
  При каждом тапе или клике в любом месте экрана прямо поверх карточек разлетаются нежные трехмерные лепестки сакуры.
* ✨ **Магический шлейф искр (Touch Sparkles Trail)**:
  При скролле пальцем по экрану за движением рассыпаются золотые мерцающие звездочки `✦`.
* 🌟 **Золотой перелив (Foil Shimmer) на именах**:
  Имена молодоженов переливаются благородным градиентом тисненого золота и шелковой розы.
* 🎵 **Романтическая музыка без внешних аудиофайлов (Web Audio API)**:
  В правом верхнем углу расположена элегантная кнопка включения фоновой мелодии (арпеджио арфы и глубокий бас виолончели), которая генерируется прямо в браузере.
* 📅 **Интерактивный календарь (Октябрь 2026)**:
  Число 11 обводится анимированным сердцем. Кнопка **«Добавить в календарь»** мгновенно скачивает файл `.ics` для Apple Calendar, Google Calendar, Outlook.
* 📍 **Локация и навигация**:
  Прямые ссылки для открытия в **Яндекс Картах**, **2ГИС** и кнопка копирования адреса в один тап.
* 🎨 **Интерактивный дресс-код**:
  Палитра свадьбы с подсказками по оттенкам при нажатии на кружок цвета.
* 💌 **RSVP-анкета с динамическими полями**:
  Подтверждение присутствия (один / с парой / не сможет), выбор напитков, а также пожелание любимого трека для диджея!
* 💬 **Готовая интеграция с Telegram-ботом**:
  Возможность моментально получать ответы гостей прямо в Telegram.

## 🚀 Как включить получение ответов гостей в Telegram

В файле `index.html` найдите блок:
```javascript
const TELEGRAM_BOT_TOKEN = ''; // Вставьте токен бота из @BotFather
const TELEGRAM_CHAT_ID = '';   // Вставьте ваш ID чата из @userinfobot
```

1. Откройте Telegram и напишите боту **`@BotFather`**, отправьте команду `/newbot`, укажите имя и получите `TOKEN`.
2. Напишите боту **`@userinfobot`**, он покажет ваш персональный `Id` (число).
3. Вставьте токен и Id в указанные строки `index.html` и сохраните файл.
4. Теперь каждый раз, когда гость заполняет форму на сайте, вам в Telegram моментально приходит отчет с его именем, статусом, спутником, напитками и любимым треком!

## 🌐 Как опубликовать сайт на GitHub Pages (Бесплатно)

1. Откройте репозиторий на GitHub: [murodbek-bargida](https://github.com/dzhanmar1/murodbek-bargida)
2. Перейдите во вкладку **Settings** (Настройки).
3. В левом меню выберите раздел **Pages**.
4. В блоке **Build and deployment** выберите:
   * **Source:** `Deploy from a branch`
   * **Branch:** `main` / `/ (root)`
5. Нажмите **Save**. Через 1–2 минуты ваше приглашение будет доступно по ссылке:
   `https://dzhanmar1.github.io/murodbek-bargida/`
